ICTHub Printer for macOS

Drag ICTHub Printer.app into Applications, then open it and choose Add Printer.
When connected to the laboratory network, it configures the printer directly.
Outside the laboratory network, it opens ICTHub sign-in and keeps authorization
in the macOS Keychain.

The app is not notarized because this project has no Apple Developer signing
identity. If macOS blocks the first launch, Control-click the app in Applications
and choose Open.
