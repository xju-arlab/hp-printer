## 本次修复

1. Cloudflare 对默认 Python urllib 的 JWKS 请求返回 403；设置真实应用 User-Agent 后返回 200。客户端和 Pi 同时修复，保留签名、issuer、audience、期限、组和邮箱验证。网络取钥失败不再误报为凭据失效。
2. Windows Add-Printer 返回 0x80070005：只对打印队列配置请求 UAC 提权，浏览器登录、DPAPI 和后台仍属于当前用户。PowerShell 错误改为简洁文本。
3. Windows 内置 IPP 驱动把 printer-uri 内的队列路径改为小写。桥仅接受同一配置路径的大小写变体，再改写为 CUPS 原始队列名，其他队列仍拒绝。
4. 中文 Windows 默认 cp936 导致含中文名称的 UTF-8 设置文件读取失败，强制公网模式被误当作关闭。设置和路由文件显式使用 UTF-8，并增加中文设置回归检查。
