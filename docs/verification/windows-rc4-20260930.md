# RC4 / RC5 界面调整

## 需求与改动

- 用户要求对齐 `xju-feiyue` 的 Notion 风格，减少提示，在左栏直接显示打印机状态。
- 实验室名称按最新指示为“算法与科研实验室”，Logo 保留；系统打印机仍为“算法实验室·惠普打印机”，队列、端口和认证标识不更改。
- 参考相邻项目 `frontend/src/styles/tokens.css`、`frontend/src/features/auth/LoginForm.tsx`：白色主区域、暖白侧栏 `#f7f6f3`、正文 `#37352f`、次要文字 `#787774`、细边框 `#edece9`、6 px 控件圆角。
- 缩小 Logo、表单居中、按钮紧接输入框，去掉宣传口号、步骤编号、平台版本脚注和重复操作说明。授权确认、卸载确认、输入错误和需要管理员授权时的提示保留。
- 用户追加应用图标使用 `printer.png`：原图作为透明遮罩保留，窗口图标和打印机标记随系统深浅模式着色。左栏实验室徽标继续保留。
- 界面读取 Windows 应用颜色偏好并监听变化，浅色为暖白/深灰，深色为炭灰/浅灰。Windows 11 标题栏同步主题；Windows 10 使用系统原生标题栏。高对比度模式使用系统颜色。
- EXE/资源管理器图标使用同一打印机形状的中性浅底 ICO，含 16–256 px 多尺寸，保证深浅背景可辨认；资源管理器的静态图标不按应用主题切换，运行窗口的图标会切换。
- 左栏“惠普打印机”显示设备状态、纸张、黑色/彩色墨量和采集时间。首次打开即读取 `/v1/status`，每 15 秒刷新，超时 6 秒。
- 状态读取使用独立只读 HTTP 客户端，不使用登录工作进程或凭据管道，账号输入与状态刷新互不阻塞。
- 失败时只在左栏显示“暂不可读”，纸张显示 `—`，旧墨量变淡并标记上次采集时间，不弹窗、不打断输入。未知墨量显示 `—`，不当作 0%。

## 验收边界

本轮不新增或手动运行测试，不提交打印作业，不操作用户账号。构建、既有 CI 和发布记录见后续追加。UI 调整不代表新登录方式、安装升级或实物打印已经验收。

本机 .NET 9 / PyInstaller 构建已完成，自包含 EXE 编译成功；未运行 GUI 交互验收。

## 版本范围

RC4 更新 Windows 客户端及品牌文案。Pi 源码跟随 main 同步；生产服务继续固定在 RC3 提交 `6c5ac0bc296af2f16094ee10f2b42d5c5f6abba2`，状态 API 和 CUPS/USB 配置无需重新部署。

## Windows 构建修正

RC4 源码带入了用户图片的 `Zone.Identifier` 下载元数据。WSL 将它保存为含冒号文件名，Windows checkout 拒绝该路径，工作流 `36721436497` 在构建前失败，未生成 RC4 Release。已删除这项元数据并加入忽略规则；原 PNG 内容不变。保留 RC4 标签，后续发布版本为 RC5，不移动已有标签。
