# v0.1.0 正式发布

## 本轮修改

- 用户要求正式发布，并删除其他所有标签。正式版下载可用并完成镜像校验后，清理两端候选版 Release 与旧标签，本地同步清理；提交历史与本目录历史实测记录保留。Pi 同步受连接问题阻塞，见下方。
