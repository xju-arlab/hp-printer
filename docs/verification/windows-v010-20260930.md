# v0.1.0 正式发布

## 本轮修改

- 用户要求正式发布，并删除其他所有标签。正式版下载可用并完成镜像校验后，清理两端候选版 Release 与旧标签，本地和 Pi 同步清理；提交历史与本目录历史实测记录保留。
- `QuietButton` 的悬停改为文字从 Muted 加深到 Ink、字重 SemiBold，背景始终透明；独立模板取消继承的悬停整体变淡，保留键盘焦点边框与禁用态。
- 应用于“使用已登录账号”“注册账号”“重新发送邮件”“本机状态”“卸载打印机”。常规主按钮样式保留。
- Python 和安装器版本为 `0.1.0`；Windows 文件版本为 `0.1.0.10`，接续 RC9 的构建修订号。
