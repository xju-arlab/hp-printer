# RC8 登录表单与小尺寸 Logo

## 用户反馈与修复

- Logo 模糊：原图仍保留 512×510，使用 `scripts/build-lab-logos.ps1` 从原图预导出 36、48、60、72、96、120、144、192 px PNG，保持图案内容与比例。侧栏显示 48 DIP，常见 100–400% Windows 缩放使用对应像素图，窗口跨屏时重新选择。标题栏改用已有 16–256 px ICO，取消中间 64 px 位图的再次缩放。
- 输入框留白过多：WPF 的 TextBox/PasswordBox 会将 Padding 传给内部 ScrollViewer，旧模板外层 Border 又重复使用。移除 Border 的重复 Padding，保留单层水平 10、垂直 7，最小高度 38 DIP。空错误/进度文字折叠，避免按钮上方空白。
- 点击登录或验证会清空：删除发送请求后和普通页面切换时的清空操作。请求中、验证失败或网络错误时保留 PasswordBox 内的输入，不写入设置或日志；认证成功、主动返回/离开登录页、关闭窗口才清空。每次请求只传当前阶段需要的字段，验证码阶段不再次发送密码。
- 验证页标题改为“动态验证码(Authenticator)”，输入标签为“验证码”。保留恢复码协议支持，不增加新提示。
- 表单控件重新启用后再恢复焦点；延续 RC7 默认白色主题与 RC6 覆盖安装。

Padding 行为依据：[TextBoxBase 源码](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Controls/Primitives/TextBoxBase.cs)、[PasswordBox 源码](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Controls/PasswordBox.cs)。

## 验收边界

本轮生成图片资源并构建发布，不新增或手动运行测试。未用真实账号提交密码/验证码，未进行 GUI 或跨屏 DPI 的实机验收，不将编译成功写成登录验证成功。Pi 仅同步源码与记录，生产服务仍固定 RC3。
