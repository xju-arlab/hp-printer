# RC3 图形安装器与状态 API

日期：2026-09-30。用户新增要求为 Windows 图形向导、窗口内 Authentik 验证、统一“算法实验室”品牌和提供的 Logo；随后明确状态能力为 API，不做网页。

## 已实现

- `windows/ICTHubPrinter.Setup`：C# WPF、自包含 Windows x64 单 EXE。安装、重新登录、状态、卸载均使用窗口；嵌入的 Python 后台通过隐藏进程运行。EXE 和窗口使用用户提供的实验室 Logo。
- 账号密码、动态验证码/恢复码、显式授权步骤通过 Authentik Flow Executor 执行。沿用 Authorization Code + PKCE、state、nonce 和 JWT 检查，不启用密码授权模式、不需要 client secret、不打开浏览器、不监听登录回调端口。
- 只向固定 Authentik HTTPS 来源发送请求。登录数据经过父子进程私有标准输入管道，不放在命令参数、磁盘文件或日志。令牌仍由 Python 使用当前用户 DPAPI 保存。
- Captcha、安全密钥和其他未实现的登录阶段会明确报错；不绕过账号验证策略。账号注册/找回仍在现有账号站点办理。
- 保留 RC2 的内置 IPP 驱动、LAN 优先、公网转发和凭据格式；更新安装后开始菜单入口及 Windows 卸载入口指向 GUI。不会更改默认打印机。
- `/v1/status` 提供公开只读 JSON：物理设备状态、纸张报告、墨盒估计百分比、CUPS 对照读数、时间和过期标记，15 秒缓存。详见 [API 契约](../10-status-api.md)。

## 构建与回退

Windows 安装 .NET 9 SDK、uv 后运行 `scripts/build-windows.ps1`。该脚本先锁定 Python 依赖并生成后台，再将后台作为资源嵌入 WPF EXE。桌面仅负责界面，Pi 继续是 Python + uv。

RC2 Release 和标签保留，必要时用 RC2 重装客户端。Pi 通过 `scripts/install-pi.sh` 的不可变 release 目录切换，原 CUPS、USB 和 Tunnel 配置保留；服务健康检查失败会恢复前一版本。
